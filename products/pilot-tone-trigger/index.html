//  What it does

A pilot tone drops — a playback machine, a Waves server, a plugin host — and the console switches to the backup you already built. No switching hardware. Pilot Tone Trigger listens for a pilot tone on the path you can't afford to lose and the instant it drops recalls a Scene, fires an Action, or both: main/backup playback switched at the console, or the "inserts out" scene for a dead Waves server, pulled automatically.

  • Detects loss of a pilot tone on any critical path — playback, Waves / SoundGrid, plugin hosts, outboard
  • Switches the console to your backup in milliseconds — a Scene, an Action, or both
  • Main / backup playback with no switching hardware — an Action moves the input source from Preamp A to B
  • Pulls the "inserts out" scene when SuperRack, LiveProfessor, Gig Performer or MainStage dies
  • Signal Integrity — catches a tone that's present but damaged, and warns or fails over
  • Automatic failback, latch until you reset, or Flip A/B by hand
  • Fails safe — stopping the app never fires a failover
  • Full-featured 20-minute trial

//  Why I built it

Playback redundancy has always meant hardware. A Radial SW8 is excellent, but it’s about $1,400, it’s heavy, it switches eight analog channels, and it sits between the interfaces and the desk — and everyone knows D-subs are a pain. The PlayAUDIO boxes do a similar job for around $1,200; the Dante-capable DirectOut unit is over $3,000. All of them need a hardware interface on each machine, and the analog ones can’t switch a source that arrives at the console digitally. On a dLive you can already build the backup — an Action that moves each channel’s input source to the B machine, or a Scene that takes every insert out when the plugin server dies. What was missing was something that fires it faster than a person can. So I wrote that.

//  In detail

Listens for a pilot tone.

A continuous tone on the path you can’t afford to lose — from the app’s own generator or your own. Any input on any interface the Mac can see (Dante, SoundGrid, MADI, Thunderbolt, USB, PCIe), on any channel.

Fires your backup when it drops.

A Scene recall, a console Action, or both, sent to the dLive in milliseconds. You build the backup once, on the console, the way you’d build it anyway.

Main and backup playback, no switching hardware.

Both playback machines feed the console directly — over Dante Virtual Soundcard, the SoundGrid driver, or any interface. The Action switches each channel’s input source from Preamp A to B. Whatever the tracks run in — Ableton Live, Reaper, Logic, Cubase — makes no difference.

The “inserts out” scene, automated.

If you mix through SuperRack, SuperRack Performer, LiveProfessor, Gig Performer, MainStage or another plugin host, you already have the Scene that bypasses every insert. Pilot Tone Trigger pulls it the instant the server stops passing the tone.

Checks the tone is clean, not just present.

Signal Integrity watches how much of the incoming audio actually sits at the tone’s frequency, so clicks, dropouts, noise, clipping and a garbled tone all show up — the ways a digital path degrades before it fails outright. Warn only, or fail over. Off by default; tune it to your own rig.

Fail back your way.

Automatically when the tone returns, or hold on the backup until you press Reset — so the desk never flips back onto a source that just failed. Reset won’t fire while the tone is still missing. Flip A/B switches by hand any time, whatever the detector thinks.

Catches a feed that’s already dead.

Press Start on a path that’s already down and it fails over immediately.

Fails safe.

Stopping the app, or the trial ending, sends nothing to the console. If the Mac running it dies, nothing is sent either — the show stays exactly where it was.

Know it works before doors.

Test Connection confirms the console is answering. The menu-bar icon shows tone present, tone lost, degraded, and restored but still on the backup.

Gentle on the show interface.

One input channel, a large buffer, and it never changes the sample rate.

Stream Deck control — coming soon.

Run, failback mode, Reset and the tone generator as Bitfocus Companion buttons, with the app’s state shown back.

//  Who uses it

Playback engineers and techs running tracks into a dLive; FOH and monitor engineers mixing through Waves or a native plugin host; theatre and worship productions with a backup machine and nobody spare to watch it. It needs a dLive, a Mac on the network, and the backup path already patched to the console.

//  Questions

Does this replace a Radial SW8 or an iConnectivity PlayAUDIO?

For a dLive, yes — that’s what it’s for. Those boxes switch analog outputs upstream of any console, and if that’s what you need, they’re the right tool. Pilot Tone Trigger switches at the console instead, so it costs nothing in hardware, works with digital sources, and needs the backup path patched to spare inputs.

My playback comes in over Dante Virtual Soundcard. Can hardware switchers handle that?

Not the analog ones. This can: the tone is just another channel, and the switch happens on the console.

What happens when the Waves server crashes mid-show?

If it stops passing the tone, Pilot Tone Trigger fires the Scene you’ve built with every insert out. Audio carries on through the console; nobody has to find the panic button.

Isn’t another computer just another thing that can fail?

If Pilot Tone Trigger stops — or the Mac does — nothing is sent, and the console stays on the main rig exactly as it was. It can only ever fire the backup you built.

How fast is it?

The detector’s defaults are a 50 ms dropout hold and a 30 ms envelope release, so the switch is sent in milliseconds. A measured end-to-end figure on a console is coming.

What does it need?

A dLive, a Mac on the console’s network (Direct TCP, or through the free MIDI Bridge), a pilot-tone feed into any audio input, and the backup — a Scene, an Action, or both — built on the console.

Does it work with other consoles?

It’s built for the dLive. Users report it works on Allen & Heath Avantis with Scene recall — Actions are a dLive feature — though I haven’t tested that myself yet. Other consoles are being looked into — register your interest and say which desk. (Time Code Tool already works with anything.)

Windows? Intel Macs?

Built for Apple Silicon. From this version the app also installs and runs on Intel Macs — verified so far in a VM, with testing on Intel hardware in October — so if you’re on Intel, try the free trial and tell me how it goes. Windows is being looked into — register your interest.

Does it phone home?

No analytics, no telemetry. Activating the licence is the only network call; Check for updates runs only when you press it, and nothing goes online while a trigger is armed. A licence covers two Macs — show machine and spare.
