# changelog/

Copies of each app's `CHANGELOG.md` from the apps repo
(`apps/<slug>/CHANGELOG.md`). The product pages' "What's new" section is
built from the top entry and shown once `updates/<slug>.json` has the same
version.

**One deliberate difference:** public copy says Apple Silicon only until
the operator confirms Intel on a physical Mac (operator, 27 Sept 2026), so
the Intel wording is taken out of these copies — MIDI Bridge 1.3.0's first
bullet, and a clause in the first bullet of TLT 1.2.0, PTT 1.2.0 and
TCT 1.3.0. When the next round is copied in, do the same until that
changes.
